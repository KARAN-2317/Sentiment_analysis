# SentimentX AI

An NLP-based sentiment analysis application for reviews,
customer feedback and social-media text.

## Features

- Positive, negative and neutral classification
- Custom text analyzer
- CSV bulk analysis
- Interactive Plotly charts
- CSV export

## Technologies

Python, Streamlit, Scikit-learn, Pandas and Plotly.

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
